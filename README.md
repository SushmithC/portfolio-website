# Portfolio Website

My personal portfolio site, built from scratch as my first GitHub project.

## What it is

A simple, responsive personal website with:

- A hero/intro section
- An About Me section
- A Projects section
- A Contact section
- One small interactive JavaScript feature (a "Say hi" button)

## Built with

- HTML
- CSS
- JavaScript (no frameworks — just the basics)

## Running it locally

Just open `index.html` in your browser. No build step needed.

## What I'm learning

- How to structure a webpage with HTML
- How to style it with CSS (flexbox, grid, responsive layout)
- How to add interactivity with JavaScript
- How to use Git and GitHub to track and share my work
